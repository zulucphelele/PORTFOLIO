Target Audience

  • Prospective students
  • University staff

My Role

  • Designed the complete website layout

  • Styled the website using CSS3

  • Published the project using GitHub
  • Tested the website for responsiveness

HTML5 CSS3 JavaScript GitHub Visual Studio Code

The challenge was to design a poster that would quickly capture attention while presenting information in a clear, organised and visually appealing format. The design needed to reflect the professionalism of the School of Government and effectively communicate with students.

Target Audience

  • Current NWU students
  • Prospective students
  • Visitors to the School of Government

My Role

  • Developed the design concept
  • Created the complete poster layout
  • Selected typography and colour palette
  • Designed the visual hierarchy
  • Prepared the final artwork

Tools Used

Canva Graphic Design Visual Communication Branding

Target Audience

  • Family members
  • Friends of the couple

My Role

  • Planned the visual concept
  • Designed the invitation layout
  • Edited the complete video
  • Added animations and transitions
  • Selected typography and colour palette
  • Synchronised music with visuals
  • Produced the final invitation video

Tools Used

CapCut Canva Video Editing Motion Graphics Typography

Reflection

This project strengthened my video editing, storytelling and motion graphics skills. It also reinforced the importance of designing content that is both visually attractive and suited to its intended audience.
